# image-compress-pdf

> English version: [README.en.md](README.en.md)

纯前端、本地运行的「图片批量压缩 · 打包 ZIP · 合成 PDF」工具。单文件 `index.html`，无需安装、无需服务器，双击即用。

![页面截图](docs/screenshot.png)

## 功能
- **批量压缩**：导入 JPG / PNG，可调压缩质量（0.1–0.95），松开滑块自动重压。
- **打包 ZIP**：一键将所有压缩图打包下载。
- **合成 PDF**：一键合成，支持多种排版：
  - 铺满居中（竖版 A4，不变形）
  - 智能横竖自适应（横向图用横版 A4，白边更小）
  - 裁切铺满（不留白，可能裁掉边缘）
  - 按原图比例页面（精确还原）
  - 一页多图拼版（2×2）
- **排序**：手动拖拽卡片 / 按名称 / 按修改时间，顺序同时影响 ZIP 与 PDF。
- **中英文界面**：右上角一键切换。

## 使用方法
用浏览器打开 `index.html` 即可。所有处理在本地完成，不上传任何服务器。

## 隐私
所有图片处理均在你的浏览器本地进行，不会被上传到任何服务器。
